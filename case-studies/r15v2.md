# Case study — A controlled powertrain-learning program

**Problem:** distinguish engine-management learning, research planning and actual vehicle experiments.

**Approach:** preserve stock control; learn load estimation and timing with dimensional calculations; qualify instrumentation separately; define repeated baseline conditions before comparing changes.

**Implementation evidence:** independently written study map, a pulse-frequency/cycle-time worked example and an explicitly unexecuted stock-baseline plan. No paid-course material, calibration file or vehicle-control software is included.

**Result boundary:** 100 Hz at one pulse/revolution implies 6000 RPM mathematically. That is a synthetic example, not a measured Yamaha result. No performance, torque, AFR, fuel-economy or emissions benefit is claimed.

**Next:** document actual vehicle condition and approved measurement interfaces, complete the bench logger gate, then run a supervised stock-fuel baseline with reference measurements.
